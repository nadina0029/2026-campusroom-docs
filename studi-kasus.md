# 📚 Studi Kasus: Campus Room Management

## 1. Latar Belakang Masalah
Saat ini, proses peminjaman ruangan di kampus masih dilakukan secara manual. Hal ini menyebabkan:
- Data peminjaman mudah tercecer
- Status peminjaman sulit dipantau
- Riwayat penggunaan ruangan tidak terdokumentasi dengan baik
- Tidak tersedia data rapi untuk evaluasi

## 2. Solusi yang Ditawarkan
Membangun sistem berbasis web yang memungkinkan:
- **Pengecekan Real-time:** Mahasiswa bisa melihat ketersediaan ruangan.
- **Booking Online:** Pengajuan peminjaman dilakukan lewat aplikasi.
- **Approval Digital:** Admin dapat menyetujui atau menolak dari dashboard.

## 3. Pengguna (Actors)
- **Mahasiswa:** Melihat ruang kampus, mengajukan peminjaman.
- **Admin:** Mengelola data ruangan, memvalidasi peminjaman.
