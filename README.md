# 📚 Dokumentasi Proyek Campus Room

Repository ini berisi seluruh dokumentasi teknis dan non-teknis untuk pengembangan aplikasi **Campus Room Management System**.

## 📂 Daftar Isi Dokumentasi

### 1. [Studi Kasus & Analisis](./studi-kasus.md)
Dokumen ini menjelaskan:
* **Latar Belakang:** Masalah peminjaman ruangan manual yang sering bentrok.
* **Solusi:** Aplikasi berbasis web untuk peminjaman ruangan.
* **Aktor:** Peran Mahasiswa dan Admin dalam sistem.

### 2. [Arsitektur Sistem](./arsitektur.md)
Dokumen ini menjelaskan:
* **Tech Stack:** React.js, ASP.NET Core, SQL Server, dll.

### 3. [Spesifikasi API](./api-spec.md)
Dokumen ini menjelaskan:
* **Base URL:** Alamat server backend.
* **Endpoint:** Daftar API untuk Authentication, Room Management, dan Booking.

### 4. [Refleksi Pengembangan](./refleksi.md)
Dokumen ini berisi:
* **Tantangan:** Kendala teknis (Git conflict, CORS, dll) yang dihadapi.
* **Pembelajaran:** Hal-hal baru yang dipelajari selama pengerjaan.
